Rasuk account

Masuk ke akun member tanpa perlu tahu password-nya. Password asli dicadangkan dulu di server, diganti sementara, lalu dipulihkan persis seperti semula saat Anda menekan Pulihkan. Semua sesi tercatat.

  1. Pilih akun → Rasuk
  2. Aplikasi terbuka di tab baru sebagai member itu
  3. Tekan Pulihkan setelah selesai

Server belum siap

Fitur rasuk butuh fungsi database. Jalankan supabase-rasuk-account.sql sekali di Supabase → SQL Editor, lalu tekan Muat ulang. Tanpa itu, tombol Rasuk akan ditolak server.

Sesi rasuk aktif

Tidak ada sesi rasuk aktif. Akun member dalam keadaan normal.
