FAQ

Pertanyaan yang sering muncul

Apakah harus punya akun?

Akun paket dibuat admin setelah pembayaran dikonfirmasi. Untuk mencoba gratis, buka MinimumLite dan buat sesi akun sementara tanpa email atau password.

Apa bedanya “Xozen AI” dan model lain?

Pada pilihan model, Xozen AI adalah mode otomatis: sistem memilih model yang cepat dan hemat untuk pertanyaan Anda. “Model lain” berarti Anda memilih sendiri model tertentu (Kimi, GLM, DeepSeek, GPT, dan seterusnya). Kuota keduanya dihitung terpisah. Ada juga Xozen Code dan Xozen Mini: nama lain untuk model tertentu, dan model aslinya juga tetap bisa dipilih sendiri.

Apakah aman mengirim gambar?

Gambar dikecilkan di perangkat Anda sebelum dikirim ke model. Untuk lampiran besar, file diunggah ke layanan berbagi sementara supaya bisa dibuka lewat tautan. Jangan kirim data sensitif (KTP, kartu bank, dokumen rahasia) ke layanan AI apa pun.

Bagaimana kalau kuota habis?

Sisa kuota terlihat di sidebar. Kalau habis, Anda bisa membeli paket tambahan (kuota ditambahkan tanpa menghapus akun) atau memakai model MinimumLite yang gratis.

Bisa dipakai di HP?

Bisa. Antarmukanya dibuat responsif: di HP sidebar berubah menjadi menu geser, dan pemilih model muncul dari bawah layar.

Siap mencoba Xozen AI?

Buka aplikasinya, pilih model, dan mulai dari pertanyaan pertama Anda. Butuh paket lebih besar? Admin siap membantu lewat WhatsApp.
